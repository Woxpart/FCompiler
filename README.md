# ⚡ FCompiler DE

> **Fast • Lightweight • Developer-focused Java Build System**

FCompiler DE, Java projelerini hızlı bir şekilde **derlemek, paketlemek ve çalıştırmak** için geliştirilmiş hafif bir build sistemidir.

Özellikle küçük ve orta ölçekli Java projelerinde karmaşık build sistemlerine ihtiyaç duymadan Java kodunu kolayca derleyip JAR olarak paketlemenizi sağlar.
